# nithin.yadav.portfolio

Personal portfolio website for Nithin Yadav, built with Next.js.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Framer Motion / GSAP
- Three.js (for interactive visuals)

## Features

- Interactive hero section and animated UI
- Project showcase with detailed modals
- Resume modal and contact modal
- Sound effects toggle
- Responsive layout for desktop and mobile

## Local Development

Prerequisites:

- Node.js 18+
- npm

Run locally:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm run start
```

## Deploy

Recommended: deploy on Vercel.
